#
#   ./scripts/provision-headless.sh --cameras scripts/cameras.example.txt --dry-run
#
# Mỗi dòng một camera, các cột ngăn bằng dấu |  (dùng | chứ không phải dấu phẩy
# vì mật khẩu và query string trong URL RTSP hay có dấu phẩy):
#
#   tên | rtsp chính | rtsp phụ | cổng onvif | ghi hình | ptz
#
# Bốn cột cuối bỏ trống được — mặc định: rtsp phụ rỗng, onvif 80, ghi hình true, ptz false.
# Dòng bắt đầu bằng # và dòng trống bị bỏ qua.
#
# Tên là thứ hiện trên UI và là thứ script dùng để biết camera đã có hay chưa,
# nên đổi tên trong file rồi chạy lại sẽ THÊM MỚI chứ không sửa camera cũ.
# Sửa camera đã có thì dùng /api/edit-camera, không phải script này.
